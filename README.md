**SIEMAWAW.PL** is a custom-built, private web portal and social dashboard designed exclusively for 5th-grade technical high school students (**Class of 2026–2027**) in Warsaw. The platform brings classmates together in one modern, cyber-styled hub featuring real-time countdowns to key academic milestones and an integrated community chat.

🔗 **Live Website:** [siemawaw.pl](https://siemawaw.pl) *(Login required)*

---

## ✨ What's Inside?

* **⏳ Real-Time School Year Progress:** A dynamic progress bar displaying the exact percentage of the final school year completed, paired with a glitch-styled main countdown timer to graduation.
* **📅 Milestone Event Grid:** Dedicated countdown cards tracking the most important dates of the year:
  * **Matura Exams (Basic Level):** Polish (`04.05.2027`), Mathematics (`05.05.2027`), English (`06.05.2027`)
  * **Holidays & Breaks:** Christmas (`25.12.2026`), New Year's Eve (`31.12.2026`), Winter Break (`01.02.2027`)
* **📊 Quick Stats Dashboard:** Instant overview of the current date, total days and months remaining until the end of school, and a live countdown to the nearest weekend.
* **👥 Live Community & Role System:**
  * Protected access with PHP session authentication.
  * Real-time **Online / Offline** activity list showing who is currently hanging out on the site.
  * Custom user badges (`✓` Verified, `ADMIN`, and moderation labels).
* **💬 Built-in Group Chat:** Integrated real-time chat room for registered classmates.
* **🍂 Dynamic Seasonal Atmosphere:** Pure CSS animated overlays that change with the seasons (falling autumn leaves, bats, ambient sparks) and special birthday triggers for users.

## 🔒 Privacy & Access

This repository serves as a showcase for the **SIEMAWAW.PL** web application. Due to user privacy and closed community guidelines, the source code is not publicly distributed and access to the platform is restricted to authorized students.
